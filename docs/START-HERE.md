# 🚀 Gmail Guard – Easy Start

**🇬🇧 English** · [🇩🇪 Deutsch](START-HERE.de.md) · [← back to README](../README.md)

**Goal:** Hermes manages your **whole Gmail mailbox**, and you stay in control.

> ℹ️ Tool messages and the optional Telegram bot are currently in **German**.

## 🎯 What you get

- 🏷️ Hermes creates **labels** and **sorts** your mail
- 🚫 Hermes filters out **spam** and newsletters
- 👀 Hermes watches **what comes in** and writes **reply drafts**
- 🔗 Hermes sends you the **link straight to the draft in Gmail**
- ✅ **Only you send**, in Gmail itself

⏱️ **Time:** about 40 minutes the first time. You need **no Python and no terminal on your computer**, just a browser and Coolify.

---

## 🧭 How it is built

```
Hermes (stays where it is) ──► MetaMCP ──► Gmail Guard (your server, Coolify) ──► Gmail
                                              └─ the Google key lives here
```

**The key lives on the server, never with Hermes.** That is why a crafted mail can't make Hermes steal the key. More: [README → Security model](../README.md#️-security-model).

> ⛔ **Most important rule:** Hermes must have **no access to Coolify** (no API token, no login, no SSH key to the server). Otherwise it could change the code and redeploy it, and the whole lock is worthless.

## 🧰 What you need

- [ ] A Google account (the Gmail Hermes should manage)
- [ ] Coolify on a server (and MetaMCP there, if you use it)
- [ ] A browser

## 1️⃣ Prepare Google ⏱️ 15 min · 🌐 browser

This is the longest part. It gets easy afterwards.

1. Open [console.cloud.google.com](https://console.cloud.google.com)
2. Project picker → **New project** → name `hermes-gmail` → **Create**
3. Search bar: **Gmail API** → **Enable**
4. Search bar: **Google Auth Platform** → **Get started**
   - App name `Hermes Gmail`, support email: yours
   - Audience: **External** (Workspace company account: **Internal**)
   - Contact email: yours → finish
5. Left: **Audience** → under **Test users** → **Add users** → enter **your Gmail address** → Save
   - ⚠️ In test mode access expires after **7 days**. Then repeat phase 3 once (2 minutes).
   - *Permanent, no expiry:* fill in **Branding** (home page, privacy link, domain) → **Audience → Publish app**. You can do this later.
6. Left: **Clients** → **Create client** → type **Desktop app** → **Create**
7. Note **Client ID** and **Client secret** (shown on the page, or in the downloaded JSON as `client_id` and `client_secret`)

✅ **Done when:** you have **Client ID** and **Client secret**.

> 💡 At login you will see "Google hasn't verified this app". It is **your own app**. → **Advanced** → **Continue**.

---

## 2️⃣ Start in Coolify ⏱️ 10 min · 🖥️ Coolify

1. **Project → + New Resource →** Public Repository
2. URL: `https://github.com/oliverhees/hermes-gmail-guard`
3. **Build pack: Docker Compose** · **Compose file:** `/docker-compose.coolify.yml`
4. **Environment Variables** → enter these three:

| Name | Value |
|---|---|
| `GOOGLE_CLIENT_ID` | the Client ID from phase 1 |
| `GOOGLE_CLIENT_SECRET` | the Client secret from phase 1 |
| `GUARD_MODE` | `full` (manage mailbox + drafts) |

5. **Do not assign a domain** ❌ (Gmail Guard must not be reachable from the internet)
6. **Deploy**

✅ **Done when:** the logs show **"gmail-guard startet | Modus: full | Konten: KEINE"**. ("KEINE" = none, that is correct, the account comes next.)

> 💡 The encryption key and the password for MetaMCP are generated by the server on first start and remembered in its storage (volume `guard-data`). You don't create or paste anything.

---

## 3️⃣ Connect the Gmail account ⏱️ 3 min · 🖥️ Coolify terminal + 🌐 browser

1. In Coolify: resource → service **gmail-guard** → **Terminal**
   *(Alternatively on the server: `docker ps`, then `docker exec -it <name of gmail-guard> sh`)*
2. Type:
   ```
   python -m app.connect
   ```
3. Short name: Enter (`privat`)
4. A **link** appears. Open it in your browser and sign in with the **test user account**. Click **Advanced → Continue → Allow**.
5. The browser then shows an **error page** ("site can't be reached"). **That is correct.**
6. Copy the **complete address** from the browser bar (starts with `http://localhost:8080/?state=…`) and paste it into the terminal. Enter.

✅ **Done when:** "✅ Hermes darf jetzt …@gmail.com verwalten" appears. No restart needed.

---

## 4️⃣ Connect MetaMCP ⏱️ 5 min · 🖥️ MetaMCP

1. In the Coolify terminal of gmail-guard:
   ```
   python -m app.connect --show
   ```
   → copy the **MetaMCP bearer token**
2. MetaMCP must be in the **same Docker network**: Coolify → **MetaMCP** → *Advanced* → **Connect to Predefined Network** ✔ → restart
3. **MCP Servers → New:** type **Streamable HTTP** · URL `http://gmail-guard:8000/mcp` · bearer token from above
4. **Namespace → New:** `gmail` → add **only** gmail-guard
5. **Endpoint → New:** `gmail` → namespace `gmail` → **API key required ON**
6. **Create an API key**

✅ **Done when:** MetaMCP lists the Gmail tools.

> Menu names in Coolify and MetaMCP may differ by version.

---

## 5️⃣ Connect Hermes ⏱️ 3 min · 💻 wherever Hermes runs

1. `~/.hermes/.env` → `METAMCP_GMAIL_KEY=<your API key>` (without "Bearer")
2. Paste [`hermes/config-snippet.yaml`](../hermes/config-snippet.yaml) into `~/.hermes/config.yaml` (adjust the URL)
3. Test: `hermes mcp test gmail`

✅ **Done when:** the test lists your Gmail tools.

---

## 6️⃣ Test it ⏱️ 5 min · 💬 Hermes

| # | Tell Hermes … | Expected |
|---|---|---|
| 1 | "Summarize my unread mails from today" | summary ✅ |
| 2 | "Create a draft to myself, subject: Test" | draft **+ link** to Gmail ✅ |
| 3 | Open the link and **send it yourself** in the Gmail draft | mail goes out ✅ |
| 4 | "Move 30 newsletters to trash" | Hermes gets **slowed down** (bulk brake) ✅ |

---

## 7️⃣ Turn Hermes into your inbox manager ⏱️ 5 min · 💬 Hermes

1. Put [`hermes/gmail-rules.md`](../hermes/gmail-rules.md) into Hermes' memory or a skill
2. Tell Hermes **once**:

> "Set up the labels from the section *Inbox manager* in my account `privat`. Then sort the mails of the last 3 days. Delete nothing."

3. Then **one recurring task**, e.g. every 20 minutes:

> "Work through my mailbox `privat` following the section *Inbox manager* in the Gmail rules."

✅ **Done!** From now on Hermes tells you when there is something new, with links to the drafts.

---

## 📱 Everyday use in 10 seconds

| You want to … | Then … |
|---|---|
| Check and send a draft | Open Hermes' link → check → **Send** in Gmail |
| Change a draft | edit it in Gmail, then send it yourself |
| Stop everything now | **stop** Gmail Guard in Coolify |

**Bulk brake:** If Hermes moves more than 20 mails per hour to trash/spam, Gmail Guard refuses and Hermes tells you. On the **first clean-up** of a big mailbox, work in stages (hourly).

## 🆘 Problems

| Problem | Fix |
|---|---|
| Access expires after 7 days | Test mode (phase 1, step 5). Run `python -m app.connect` again, the same short name replaces the old access |
| "GOOGLE_CLIENT_ID … fehlen" | Enter the two values in Coolify and redeploy |
| "Kein Refresh-Token" | [myaccount.google.com/permissions](https://myaccount.google.com/permissions) → remove the app → connect again |
| Browser shows `Access blocked` after allowing | Is your address listed under **Test users**? (phase 1, step 5) |
| The Coolify terminal doesn't work | Use `docker exec -it <name> sh` on the server (see phase 3) |
| MetaMCP can't reach gmail-guard | MetaMCP **and** Gmail Guard in the same network (phase 4, step 2) |
| Coolify: "network coolify not found" | On the server run `docker network ls`: is it named differently? Adjust the name in `docker-compose.coolify.yml` |
| Second account | `python -m app.connect --name firma` |
